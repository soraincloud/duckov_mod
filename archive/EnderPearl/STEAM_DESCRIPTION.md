## English Description

Version: v1.0.7
Updated: 2026-03-18
Update Notes: Fixed the severe frame drops that could happen while holding the Ender Pearl.

Adds a throwable item called the Ender Pearl. When used, it launches a projectile that teleports the player to the landing point on its first impact, with matching particle and sound effects.

### Features

- Adds a new throwable mobility item: Ender Pearl
- Teleports the player to the target location on first impact
- Includes particle and sound feedback for teleportation
- Adds a dedicated `MC` category in the workbench and storage UI
- Fixes model conflicts when the item is dropped on the ground
- Improves handheld model performance to reduce severe frame drops
- Great for fast movement, terrain traversal, and combat repositioning
